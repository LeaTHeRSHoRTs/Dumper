# Dumper

Dumper is a minecraft mod that is used in conjunction with MineBook to scrape data from minecraft

## Usage

Install dumper in your forge modpack, and then launch the client. It will go through three steps

1. Scrape data folder
2. Scrape assets folder (this must be done by creating a new world and opening it)
3. Quit the game, leaving all the scraped data in the minecraft/dumper directory

The dumper directory consists of many different JSON files. They include:
- biomes.json
- blocks.json
- effects.json
- enchantments.json
- entities.json
- fluids.json
- items.json
- mods.json
- assets folder
  - blockstates.json
  - lang.json
  - models.json
- data folder
  - advancements.json
  - loot_tables.json
  - recipes.json
